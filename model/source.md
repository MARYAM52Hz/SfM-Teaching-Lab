# Model Source

The 3D skull model used in this project is based on the **Phineas Gage Skull** provided by the **NIH 3D Print Exchange**.

Official source:
https://3d.nih.gov/entries/3DPX-003118

The model is used for **educational and research purposes** in a Structure-from-Motion (SfM) laboratory exercise.

Please refer to the original NIH page for licensing and attribution details.
